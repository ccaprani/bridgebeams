# Global source research

The September 2026 expansion records original source titles with English
translations, source URLs, access results, dimensional facts and outstanding
blockers. Source availability and implemented geometry are separate: a
manufacturer's product page can be useful evidence without providing enough
dimensions to reconstruct its sections.

Original publications retain their own copyright. Downloaded source PDFs
are not distributed with the package. The reports retain URLs and, for
downloaded documents, file hashes and page references to support retrieval.

An unsuccessful search is a bounded result, not proof that a country's
catalogue does not exist. Missing dimensions remain explicit blockers;
interpolated or assumed values are not labelled as transcriptions.
